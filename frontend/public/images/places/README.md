# Фото мест

Сюда кладутся фотографии для карточек. Пока файла нет, карточка показывает генеративную
обложку (цвет + узор из `seed.json`) — сайт не ломается.

## Как подключить

1. Положи файл, например `art-museum.jpg`, в эту папку.
2. В `frontend/src/data/seed.json` у места добавь поле:

   ```json
   "image": "images/places/art-museum.jpg"
   ```

3. Проверь: `npm run validate:data` (он убедится, что файл существует), затем `npm run dev`.

Путь указывается от корня сайта. Абсолютные URL (`https://…`) тоже поддерживаются. На GitHub
Pages префикс `/NSKproject/` подставляется автоматически.

## Требования к файлам

- Формат: WebP (лучше) или JPEG.
- Размер: 1200×800 px, вес до 200 КБ — карточки и hero режут по `object-fit: cover`.
- Имена: латиница, дефисы, совпадает с `id` места (`loft-podzemka.jpg`).
- Не используй чужие фото без прав. Свои снимки, партнёрские материалы или Unsplash/Pexels
  с соблюдением лицензии; для CC BY нужна атрибуция — добавь её в описание места или в
  отдельный файл credits.
